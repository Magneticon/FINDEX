# FINDEX
Tool for checking of existence of elements in text list.

**How to use it:**

1) Put list of strings, which you want to search for in the INPUT 1 field - they must be delimited by new line separator (each line is 1 item to search)
2) Then put text into the INPUT 2 field - for example, a job output, where you want to search for text occurrence
3) Then choose, how you want to conduct the search:

SEARCH CASE INSENS. - Search case insensitive - finds any match regardless of text case, even if it will be in the middle of another word
SEARCH CASE SENS. - Search case sensitive - finds any match which will match text case (i.e. ASDF will match with ASDF, but it won't match with AsDf), even if it will be in the middle of another word
SEARCH WORD CASE INSENS. - Search whole words case insensitive - finds any word match regardless of text case. Substrings, which are part of another string won't be returned
SEARCH WORD CASE SENS. - Search word case sensitive - Search whole words case sensitive - finds any word match which will match text case (i.e. ASDF will match with ASDF, but it won't match with AsDf). Substrings, which are part of another string won't be returned
